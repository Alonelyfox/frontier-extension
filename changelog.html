✦
v1.11.1Fix
  • Enlarged and darkened the category count numbers (e.g. Blacksmith (6)) and the build version tag at the bottom of the page — both were too small/faint to read comfortably.
v1.11Feature
  • Category groups in the Recorded Goods list are now collapsed by default, with an item count next to each (e.g. "Tailor (4)"), so the master list is much easier to scan.
  • Added Expand all / Collapse all buttons above the list.
  • Which categories you have open is remembered locally in your browser while you work — it isn't synced to the shared database.
v1.10Feature
  • Clicking Edit on a recorded good now brings the edit form down to sit right below that item instead of requiring a scroll back to the top of the page.
  • Added an "Editing: [item name]" label and a highlighted border on the form while editing.
v1.9Feature
  • Added an optional Category field to each recorded good (e.g. "Tailor," "Blacksmith"), with autocomplete suggesting categories already in use.
  • The Recorded Goods list is grouped by category, and each card shows a small category badge.
  • Calculator dropdowns now show the category alongside the item name, e.g. "Cloth Roll (Tailor)."
v1.8Feature
  • Added an optional image URL field to each resource line, with a live thumbnail preview.
  • Typing a resource name that already has a known image elsewhere auto-fills that image.
  • Thumbnails now show up on recipe cards, in the calculator's breakdown tree, and in the flat raw-materials total list.
v1.7Fix
  • Removed a leftover duplicate status indicator with hardcoded "Connecting..." text and a non-functional Refresh button that was sitting on top of the real (working) status indicator.
v1.6Feature
  • The calculator can now queue up several different goods at once — "+ Add another good" adds a row, each with its own item and quantity, with a way to remove rows too.
  • Reckoning shows a breakdown for each good, plus one combined total raw-materials list for everything requested.
v1.5Feature
  • Recipes can now specify how many units a single craft produces (e.g. 1 craft of Shell Casing makes 5).
  • The calculator works out how many times you'd need to craft something to cover the amount needed, and scales sub-resources by that number of batches instead of the raw requested quantity.
v1.4Fix
  • Resource names are now matched to recorded goods regardless of capitalization or stray spacing, so a mismatched reference (like "shell casing " vs. "Shell Casing") correctly expands into its sub-requirements instead of being treated as a raw material.
  • Saving a good that only differs by case/spacing from an existing entry now updates that entry instead of creating a near-duplicate.
v1.3Fix
  • Baked the Firebase project configuration directly into config.js, so the extension works immediately out of a fresh download without manual setup.
v1.2Feature
  • The calculator's results now lead with the crafting breakdown — tagging each requirement as "craft this" or "raw material" — instead of leading with a flat raw-materials list.
  • The flat raw-materials list is still available, moved into a collapsed "Show total raw materials only" section.
v1.1Fix
  • Fixed the live-sync connection getting permanently stuck on "Connecting..." after about an hour — it now re-authenticates and reconnects automatically instead of retrying forever with an expired token.
  • Added the build version number shown at the bottom of the page.
v1.0Initial release
  • Frontier Ledger extension: record crafting recipes (including goods built from other recorded goods) and calculate what's needed to make more.
  • Clicking the toolbar icon opens the ledger in its own tab.
  • Data is shared in real time with everyone using the extension, backed by a Firebase Realtime Database with anonymous authentication.
